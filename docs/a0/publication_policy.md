# A0：许可证与产物发布策略

状态：**Accepted for A0**
版本：`0.1.0`
决策日期：2026-09-01

## 1. 仓库原创内容

- 本仓库原创代码、文档、Schema、配置和脚本采用 Apache License 2.0；
- 许可证原文见 [`LICENSE`](../../LICENSE)；
- 版权标识暂记为 `Copyright 2026 PatchAlign-Cpp contributors`；
- 外部贡献除非明确标记为 `Not a Contribution`，按 Apache-2.0 第 5 节处理；
- 仓库许可证不覆盖模型、数据集、benchmark repository、生成补丁或第三方依赖。

## 2. Adapter 与 checkpoint

| 类型 | 默认策略 | 公开前条件 |
|---|---|---|
| 正式 SFT/DPO adapter | 可以公开 | 基础模型条款、训练数据许可、敏感信息、模型卡和完整哈希通过审计 |
| 中间 checkpoint | 不公开 | 只有形成明确复现价值并通过相同审计后才可例外发布 |
| optimizer/scheduler state | 不公开 | 原则上只作为内部恢复产物 |
| G0 Job 90719 smoke adapter | 不公开 | 仅作为环境兼容证据保留在集群 |

正式 adapter 的许可证必须在发布时结合基础模型及训练数据审计单独确定，不能仅凭本仓库 Apache-2.0 自动推导。

## 3. 数据与派生数据

- 未完成逐来源许可审计前，不公开原始样本、重打包数据集或含受限源码的派生数据；
- 可以公开处理代码、Schema、来源清单、revision、哈希、去重规则和不含受限内容的自建 fixture；
- 每个样本必须保留来源、许可证/审计状态和 revision；
- benchmark、训练集与验证集按仓库族隔离，许可审计与污染审计分别记录；
- 若来源只允许评测或禁止再分发，只公开复现说明、索引或哈希，不复制内容。

## 4. 预测、报告与日志

- 默认公开聚合指标、实验配置、Git commit、模型身份、seed、Job ID 脱敏值和可复现报告；
- 完整预测补丁只有在来源代码许可、敏感信息和漏洞披露检查通过后才能公开；
- 原始日志、内部用户名、集群节点、绝对内部路径、环境变量和潜在密钥不公开；
- 公开报告中的集群路径按稳定 artifact ID 或脱敏占位符表示；
- 失败结果不得因发布策略而从统计分母中删除。

## 5. 第三方声明

- 初始清单见 [`THIRD_PARTY_NOTICES.md`](../../THIRD_PARTY_NOTICES.md)；
- 引入第三方代码时保留其版权、许可证与 NOTICE；
- 模型和数据的许可证结论必须绑定明确 revision；
- 正式 release 前重新生成并审阅第三方清单，不能只依赖当前初始记录。

## 6. 发布门禁

任何 adapter、派生数据或完整预测发布必须同时满足：

1. 对应 artifact SHA256 和生成 Git commit 已记录；
2. 模型、数据和复制代码的来源/revision 可追溯；
3. 许可证与 NOTICE 义务已检查；
4. 密钥、个人信息、内部路径和未披露漏洞已检查；
5. 模型卡、数据卡或评测报告准确描述限制；
6. 用户对该次发布给出明确批准。

本策略定义工程发布门禁，不替代正式法律意见。
