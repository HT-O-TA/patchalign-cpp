# ADR-0024：固定分片审计后关闭 CommitPack 路线

- 状态：Accepted
- 日期：2026-09-08

## 背景

ADR-0022 只授权 CommitPack revision `5eee2c845bf88dbffcafedb6e80d2a72a43fe575`
的 `c++-0001.jsonl` 单分片静态审计，并预先禁止第二分片。ADR-0023 修正精确
Schema 值后，Job `97486` 读取全部 6,291 条记录并完成 `412 passed`，得到 cap 后
train 236、validation 17。

预注册静态份额门为 train 1,400 条、100 个新仓库、700 个 sampling family；
validation 140、20、70。除 train 新仓库数外全部未通过。legacy 与本分片合计仅为
train 496、validation 148，train 距 2,000 容量探针仍缺 1,504 条独立来源数据。

## 决策

1. 将 CommitPack 固定单分片审计标记为真实完成、静态份额门失败；
2. 不下载或抽查第二分片，不以同来源扩大样本数；
3. 不启动 CommitPack 仓库执行 pilot，不把静态许可证字段或 bug 关键词解释为真实
   buggy-fail/fixed-pass 证据；
4. 不生成训练数据，不授权 GPU、SFT 或 DPO；
5. 下一阶段只做独立可执行来源准入和 Data-v2 方法学可实现性审计；若严格全量执行
   与 2,000/200 探针被证明确实不可兼得，必须以新 ADR 显式建立静态监督层与可执行
   资格层，不能静默降低现有门槛；
6. v1 与 v1.1 artifact、原始固定分片和全部负结果继续保留，禁止覆盖。

## 后果

这项决策避免用更多同质分片追逐已失败的容量目标，也避免在没有测试复现信息的提交对上
消耗仓库构建预算。它不否定 253 条候选未来作为经额外治理的静态监督材料的可能性，
但在新契约明确前，它们不属于 Data-v2 训练集。
