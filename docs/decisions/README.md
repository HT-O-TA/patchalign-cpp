# 架构决策记录（ADR）

本目录保存项目从立项到冻结交付期间的决策历史。ADR 记录的是“在当时证据和范围下为何这样决定”，因此早期文件可能被后续 ADR 取代，但不会被改写成终态叙述。

## 阅读方式

- 当前项目结论以 [最终冻结状态](../status.md) 和 [最终实验报告](../delivery/final_report.md) 为准。
- 同一主题出现多个决策时，以编号较大的明确覆盖关系为准。
- `Accepted` 表示该决策在形成时被接受，不保证它仍是当前实施范围。
- Job ID、内部路径和中间阈值用于实验审计，不是公共运行接口。

## 关键决策链

- ADR-0001～0004：模型、输出协议、数据组成和质量门禁。
- ADR-0006～0009：A4 探索边界、执行偏好数据与阶段性收尾。
- ADR-0010～0030：Data-v2 供给、污染治理及停止条件。
- [ADR-0031](0031-resume-delivery-scope.md)：将项目切换为可复现的简历交付闭环，并恢复 A5。
- [ADR-0032](0032-dpo-selection-contract-correction.md)：修正 DPO 候选选择契约。
- [ADR-0033](0033-select-dpo-beta03-for-final-evaluation.md)：选择 beta=0.3 进入一次性最终评测。

最终评测后，DPO-beta0.3 因超时门禁失败，默认模型回退为 M1-R2；该运行结论记录在最终报告和模型卡中，而不是另行改写历史 ADR。
